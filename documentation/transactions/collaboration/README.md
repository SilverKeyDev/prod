## Collaboration and Multi-Party Workspace

This folder defines how a transaction acts as a **shared workspace** for:
- Buyers.
- Agents.
- Transaction coordinators.
- Loan officers.
- Escrow/title contacts.
- Other participants.

It covers:
- **Roles and permissions** (who can see and do what).
- **Task and checklist collaboration** (assignment, review, conflict resolution).
- **Calendar sharing** (which events each role sees and can edit).
- **Document and agreement collaboration** (who can upload, sign, and review).
- **External invites**, **audit trail**, and **notification routing**.

See:
- `01-participants-roles-and-permissions.md` for the role model.
- `02-task-and-checklist-collaboration.md` for tasks and assignment.
- `03-calendar-collaboration-and-sharing.md` and `04-document-and-agreement-collaboration.md` for shared views.
- `05-review-workflows-and-approvals.md`, `06-external-parties-and-invites.md`, `07-audit-trail-and-activity-feed.md`, and `08-notification-preferences-and-routing.md` for deeper collaboration behavior.
