## Timeline Phases and Deadlines

This folder describes the **phase-by-phase timeline** of a residential purchase transaction, including:
- Earnest money and deposits.
- Inspections and due diligence.
- Appraisal and valuation.
- Financing and loan approval.
- Title, escrow, and closing prep.
- Signing, closing, and funding.
- Move-in and post-closing tasks.

Each document focuses on:
- Inputs required (dates, contract data, jurisdiction).
- Typical deadlines and how they vary by state or contract form.
- How each phase maps to:
  - Checklists.
  - Milestones.
  - Calendar events.

The `09-state-variation-model.md` and `10-compliance-data-and-apis.md` docs explain how we handle jurisdiction-specific variations and compliance-related data.
