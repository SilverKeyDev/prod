# What this is:
#   Additional packages needed to run the Server test suite in CI after ci.txt is
#   installed. It is not a full replacement for runtime.txt: it avoids pulling every
#   large production pin while still satisfying imports used by tests (numpy/sklearn,
#   sentence-transformers, shapely, matplotlib, OpenAI client stack, etc.).
#
# Where it is used:
#   - GitHub Actions: .github/workflows/test-callable.yml
#       1) pip install -r requirements/ci.txt
#       2) pip install torch==... (CPU wheel from PyTorch index — see workflow)
#       3) pip install -r requirements/test.txt
#       4) pytest + coverage
#
# Relationship to other files:
#   - Always layered on ci.txt in CI (never the only requirements file in that job)
#   - Lint CI uses requirements/lint.txt instead (no test.txt, no torch)
#   - Full prod parity / Docker → requirements/runtime.txt
#   - Local developers usually: runtime.txt + dev.txt (pytest lives in dev.txt)
#
# flask-compress below: imported at app package load (app/__init__.py). Pin must stay
# aligned with the same line in requirements/ci.txt when versions change.
#
