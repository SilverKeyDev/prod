# =============================================================================
# requirements/ci.txt — CI LINT / IMPORT SMOKE (SLIM)
# =============================================================================
#
# What this is:
#   Enough packages for scripts that must import the `app` package (e.g. Ruff against
#   Server/, lint_circular_imports.py: `from app import create_app`) without installing
#   large wheels that are not needed on that import path (heavy ML, full torch stack, etc.).
#
# Where it is used:
#   - Layered by requirements/lint.txt (CI lint) and requirements/test.txt (CI pytest)
#   - Backend tests job (first layer): .github/workflows/test-callable.yml installs ci.txt,
#     then CPU-only torch, then requirements/test.txt
#   - Local slim venv: Server/scripts/bootstrap-venv.sh --ci (import smoke) or --lint (CI lint parity)
#
# Relationship to other files:
#   - Production / Docker → requirements/runtime.txt (superset of this file)
#   - Pytest on CI needs extra ML/geo deps → also install requirements/test.txt (and torch
#     per test-callable.yml), not this file alone
#   - When something is imported from app/__init__.py or modules loaded at import time,
#     add it here AND in runtime.txt; keep overlapping pins aligned with runtime where they
#     must match (e.g. flask-compress is duplicated in test.txt for the test install path)
#
