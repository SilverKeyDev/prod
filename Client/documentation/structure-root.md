# SilverKey Client - Root Structure

This document outlines the top-level directory structure of the SilverKey React
client application.

## Directory Overview

```text
Client/
├── .gitignore            # Git ignore patterns
├── .nvmrc                # Node.js version specification
├── .prettierignore       # Prettier ignore patterns
├── config/               # Build and development configuration files
├── coverage/             # Test coverage reports (generated)
├── dist/                 # Production build output (generated)
├── documentation/        # Project documentation and guides
├── index.html            # Main HTML entry point
├── legacy-modal.md       # Legacy modal documentation
├── legacy-search.md      # Legacy search documentation
├── node_modules/         # NPM dependencies (generated)
├── package-lock.json     # Locked dependency versions
├── package.json          # Project dependencies and scripts
├── playwright.config.ts  # Playwright testing configuration
├── playwright-report/    # Playwright test reports (generated)
├── postcss.config.js     # PostCSS configuration
├── public/               # Static assets served directly
├── scripts/              # Build and deployment scripts
├── src/                  # Source code (React application)
├── tailwind.config.js    # Tailwind CSS configuration
├── test-results/         # Test execution results (generated)
├── tsconfig.app.json     # TypeScript app configuration
├── tsconfig.json         # TypeScript main configuration
├── tsconfig.node.json    # TypeScript Node.js configuration
├── vite.config.ts        # Vite build tool configuration
└── vitest.config.ts      # Vitest testing configuration
```

## Key Directories

### `/config/`

Contains build tools and development configuration:

- ESLint rules and configurations
- Prettier formatting rules
- TypeScript configuration
- Tailwind CSS setup
- PostCSS configuration
- Vite build settings

### `/coverage/`

Test coverage reports generated by testing tools:

- HTML coverage reports
- Coverage data files
- Test execution summaries

### `/documentation/`

Project documentation including:

- Architecture guides
- Security documentation
- API documentation
- Development guides
- Structure documentation
- Package documentation
- Data retrieval guides

### `/playwright-report/`

End-to-end test reports generated by Playwright:

- Test execution videos
- Screenshots
- Test results and summaries

### `/public/`

Static assets served directly by the web server:

- HTML templates
- Icons and images
- Manifest files
- Static resources

### `/scripts/`

Build and deployment automation scripts:

- Security audit scripts
- Build automation
- Deployment utilities

### `/src/`

The main React application source code containing:

- Components and pages
- Services and utilities
- Contexts and providers
- Hooks and custom logic
- Styling and assets
- Type definitions
- Test files and mocks

### `/test-results/`

Test execution results and artifacts:

- Test output files
- Test artifacts
- Execution logs

## Development Files

- **`.gitignore`** - Git ignore patterns for version control
- **`.nvmrc`** - Node.js version specification for consistent development
- **`.prettierignore`** - Prettier formatting ignore patterns
- **`package.json`** - Project metadata, dependencies, and npm scripts
- **`package-lock.json`** - Exact dependency versions for reproducible builds
- **`index.html`** - Main HTML entry point for the application
- **`legacy-modal.md`** - Documentation for legacy modal components
- **`legacy-search.md`** - Documentation for legacy search functionality

## Build Output

- **`dist/`** - Generated production build files (created by `npm run build`)
- **`node_modules/`** - Installed NPM packages (created by `npm install`)
- **`coverage/`** - Test coverage reports (created by test runs)
- **`playwright-report/`** - End-to-end test reports (created by Playwright tests)
- **`test-results/`** - Test execution results and artifacts

## Configuration

The project uses a mix of centralized and distributed configuration:

- **`/config/`** - Centralized build tool configurations (ESLint, Prettier)
- **Root level** - Main configuration files (TypeScript, Vite, Tailwind, PostCSS, Playwright, Vitest)
- **`.nvmrc`** - Node.js version specification for consistent development environments
- **`.prettierignore`** - Prettier formatting ignore patterns

This approach keeps the most commonly modified configurations easily accessible while maintaining organization for build-specific settings.
